How the trigger controls work
Load tension
Resistance before the firing stop. Raise it for a heavier pull.
Stop / break
The firm point you push through. A shorter interval gives a sharper break.
Kick
A timed motor push. Spacing separates kicks; duration controls how long each one lasts.
Bow release
Clears tension at the high point and keeps the return free until you let go.

Force has eight hardware levels and travel has ten zones. Percent values round to those levels. Measure zones to match physical travel.

Setup & game support

In a compatible DSX mod, set its destination to 127.0.0.1 and the port above. Close DSX if it uses that port. Supported instructions: Feedback, Weapon, Vibration, slope/zone feedback, RGB, reset. Older custom modes are not translated.

A JSON integration can send {"weapon":"smg","events":["dash"]} over local UDP. Use the same weapon and event names in this profile. Events fire once per packet.

Crimson Desert, Modern Warfare, and Rematch can use input rules and manual weapon presets. Automatic weapon detection needs a compatible integration; no verified integration for these games is bundled.

Choose “Use last app” above to match the game's executable. Steam Input can stay enabled for game controls. If it or the game replaces trigger effects, turn off the competing effects or use the Xbox bridge. Native DualSense games should usually keep their own effects.
